# 🛡️ MoMo Guardian

**A security layer for mobile money — it protects people *before* they send.**

Scams don't look like fraud to a bank: the real user authorizes the payment. MoMo Guardian spots the
context that's wrong (new recipient, unusual amount, unusual behavior), explains the risk in plain
language, asks a few smart questions, and steps up verification only when it matters.

We're not building another wallet. We're building the infrastructure that makes every mobile-money
transaction safer — as a consumer experience today and a **Fraud Prevention API** for fintechs, banks,
merchants and payment platforms tomorrow.
